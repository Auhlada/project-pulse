# PROJECT PULSE

### The Heartbeat of YouTube Shorts

**Understanding, Predicting & Optimizing YouTube Shorts Performance**

*An AI-powered decision support system for YouTube Shorts creators.*

## Overview

Project Pulse is an end-to-end Data Science and Machine Learning project that aims to understand the factors influencing YouTube Shorts performance and build predictive models to estimate video performance before publishing.

---

## Business Problem

Creators often publish YouTube Shorts without knowing how well they might perform.

Project Pulse explores historical YouTube Shorts data to identify key performance drivers and develop predictive models that can assist creators in making better publishing decisions.

---

## Objectives

- Understand YouTube Shorts performance patterns.
- Identify important pre-upload features.
- Build predictive machine learning models.
- Develop an AI-powered decision support system for creators.
